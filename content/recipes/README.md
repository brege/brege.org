# Recipe Taxonomy

Recipe tags are a flat field with a few distinct purposes mixed together.

Someone should be able to land on one recipe, notice a useful trait like `vegetarian` or `fermentation`, and branch into other recipes or menus that share it.

## Tag Families

### Dish / Form

- `appetizer`
- `breakfast`
- `dessert`
- `sauce`
- `dressing`
- `seasoning`
- `baked-goods`
- `preserves`
- `pickling`
- `fermentation`

### Cuisine / Region

- `american`
- `asian`
- `german`
- `hispanic`
- `mediterranean`

Only apply a cuisine tag when the influence is real and legible, not because the recipe vaguely resembles something from that region.

### Technique / Method

- `blending`
- `candied`
- `culinary-basics`
- `emulsification`
- `poached`
- `puree`
- `sous-vide`

Use technique tags when the method is central to the recipe or likely to be a useful retrieval path.

### Diet / Compatibility

- `vegetarian`
- `vegan`
- `gluten-free`
- `dairy-free`
- `keto`

Agents: only apply diet tags when the recipe is genuinely compatible as written, or the compatibility is obvious and stable. For menu items, these are not easy to guess. Ask me if the context is at all deceptive.

## Menus

Menus should reuse the same flat tag vocabulary when the property is clear at the menu level, especially for discovery paths like `vegetarian`, `vegan`, or regional influence.
